МОЙ АССИСТЕНТ — БРАУЗЕРНАЯ ВЕРСИЯ, АУДИТ И ИСПРАВЛЕНИЯ

Запуск
1. Распакуйте архив полностью.
2. Откройте index.html в современном браузере.
3. Данные сохраняются локально в localStorage браузера под ключом
   myAssistantProFinal.v1.

Резервная копия
— «Экспорт» скачивает полную резервную копию JSON.
— «Импорт» принимает JSON, нормализует старые данные и сохраняет предыдущую
  версию в localStorage под ключом myAssistantProFinal.v1.beforeImport.
— Перед импортом важных данных рекомендуется отдельно выполнить экспорт.

Совещания и задания
Формат одной строки:
Исполнитель | Задание | Дедлайн ГГГГ-ММ-ДД | Точное название проекта

Можно использовать и обычный текст, например:
Королева должна подготовить презентацию до 15 августа 2026.

После сохранения совещания приложение ищет задачи в полях «Задания
участникам», «Решения» и «Заметки». Если фамилия однозначно совпала с
участником команды, открывается окно проверки. В нём можно изменить
исполнителя, задачу, срок и проект или снять галочку с ошибочно найденной
строки. Кнопка «Распознать задачи» позволяет повторить проверку вручную.

Участник связывается с поручением по внутреннему ID; имя сохраняется для
отображения и совместимости старых данных. Подтверждённые задачи появляются
у соответствующего человека в «Команде», в «Задачах» и в календаре при
наличии срока. Повторная синхронизация не создаёт копии.

Старые строки без разделителей поддерживаются. Старые поля совещаний
questions/tasks и поручений person/task/note автоматически мигрируют в
normalize(). Задания совещаний синхронизируются с разделами «Команда» и
«Задачи» по устойчивым ключам без повторного создания записей.

Исправлено после аудита
— открытие «Сравнения дорожных карт»;
— миграция старых совещаний и поручений;
— удаление связанных записей вместе с источником;
— стабильность идентификаторов автоматически связанных задач;
— синхронизация статуса при переносе связанной задачи в Kanban;
— версия структуры данных повышена до 4;
— элемент перетаскивания проекта больше не является кнопкой без click-функции.

Ограничения
— Google Calendar: полноценной двусторонней OAuth-синхронизации нет; доступны
  экспорт/импорт ICS, открытие Google Calendar и создание события через ссылку.
— Экспорт отчёта создаёт Word-совместимый HTML-файл с расширением .doc, а не
  настоящий .docx.
— Полноценный редактор бизнес-процессов не реализован.
— Приложение не использует внешние CDN и работает без сервера.

Подробности проверок и ограничения автоматизации находятся в QA-REPORT.txt.
