# Документация проекта «Мой ассистент»

Здесь хранится актуальная документация по продукту и процессу его разработки.

## Основные документы

- `DevelopmentGuide.md` — правила совместной работы над проектом.
- `Vision.md` — цель и видение продукта.
- `Architecture.md` — архитектура системы.
- `Roadmap.md` — этапы развития.
- `ProjectState.md` — текущее состояние проекта.
- `Decisions.md` — журнал принятых решений.
- `Glossary.md` — словарь терминов.

## Правило

Документация должна отражать реальное состояние проекта и обновляться вместе с архитектурой и процессом разработки.
