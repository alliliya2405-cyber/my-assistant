# Models

Здесь находятся модели данных приложения.

Каждая модель описывает одну сущность системы.

Планируемые модели:

- Project
- Subproject
- Sprint
- Task
- TeamMember
- Meeting
- MeetingTask
- Habit
- Quote
- Report
- Note
- Timeline
- KanbanCard

## Правило

Модель описывает только данные.

Она не должна содержать:

- HTML;
- кнопки;
- оформление;
- CSS;
- код интерфейса.
