# Task

Модель задачи в приложении «Мой ассистент».

## Назначение

Task — единая задача, которая может отображаться в разных разделах приложения.

Одна задача не должна создаваться заново для разделов «День», «Неделя», «Месяц» или «Проекты».

Эти разделы должны показывать одну и ту же задачу в разных представлениях.

## Основные поля

- `id` — уникальный идентификатор задачи;
- `title` — название задачи;
- `description` — дополнительное описание;
- `date` — дата выполнения;
- `status` — состояние задачи;
- `createdAt` — дата и время создания;
- `updatedAt` — дата и время последнего изменения.

## Статусы

На первом этапе используются два статуса:

- `active` — задача активна;
- `done` — задача выполнена.

## Даты

Внутри приложения дата хранится в формате:

`YYYY-MM-DD`

Например:

`2026-08-08`

Пользователю дата отображается в формате:

`ДД.ММ.ГГГГ`

Например:

`08.08.2026`

## Главное правило

Task является самостоятельной сущностью.

Разделы приложения не должны хранить собственные копии одной и той же задачи.

В дальнейшем к Task можно будет добавить связи с:

- проектом;
- подпроектом;
- спринтом;
- совещанием;
- участником;
- календарём.

Эти связи будут добавляться постепенно, только когда они понадобятся.
