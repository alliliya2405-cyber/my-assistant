# Core

Центральное ядро приложения «Мой ассистент».

## Назначение

На этом этапе ядро не изменяет работу приложения.

Оно создаётся как фундамент новой архитектуры.

В дальнейшем здесь будут размещены:

- модели данных;
- репозитории;
- слой хранения данных;
- миграции;
- события приложения;
- синхронизация;
- API ядра.

## Правило

До версии 2.0 интерфейс приложения не должен напрямую работать с localStorage.

Весь доступ к данным будет происходить через Core.
