# Health Habit Cards v1

## Цель

Сделать экран «Жизнь → Здоровье» быстрее для ежедневного использования: привычка и действие на сегодня должны читаться раньше технических настроек.

## Что меняется

- карточка привычки становится компактнее;
- иконка привычки получает отдельную спокойную область;
- название привычки становится главным элементом;
- «Настроить / Удалить» визуально уходят на второй план;
- «Отметить сегодня» остаётся главным действием карточки;
- мобильная версия получает полноширинную кнопку выполнения.

## Что не меняется

- `app.js`;
- данные привычек;
- расписание и напоминания;
- автоматическое создание задач из привычек;
- Pomodoro-связи;
- Data Store и localStorage;
- обработчики добавления, настройки, удаления и выполнения.

## Проверка

После публикации открыть «Жизнь → Здоровье» и убедиться, что карточки читаются компактно, а существующие действия работают как раньше.
