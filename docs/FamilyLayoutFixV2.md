# Family Layout Fix v2

Дата: 11.08.2026

## Проблема
На пользовательском скриншоте семейные записи оставались сжатыми в узкую вертикальную колонку даже после первого исправления. Причина: кнопки «Изменить / Удалить» продолжали конкурировать с текстом за ширину одной строки.

## Решение
- текст записи занимает всю ширину карточки;
- действия «Изменить / Удалить» перенесены отдельной строкой ниже текста;
- слова больше не должны ломаться на узкие вертикальные фрагменты;
- на узких экранах сохраняется адаптивная сетка.

## Не изменяется
- app.js;
- данные семьи;
- Data Store;
- создание, редактирование и удаление записей;
- route id и другие экраны.
