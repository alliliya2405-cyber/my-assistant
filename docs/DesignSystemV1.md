# Design System v1

## Цель

Сделать интерфейс «Моего ассистента» спокойнее, плотнее и удобнее для ежедневной работы, не меняя данные и бизнес-логику.

Первый этап Design System v1 применяется только к Главной / Сегодня и списку задач.

## Принципы

1. Содержание важнее декоративных эффектов.
2. Карточки должны занимать столько высоты, сколько нужно для чтения, а не создавать большие пустые зоны.
3. Основное действие заметно, вторичное действие спокойно.
4. Тени используются мягко; границы и отступы дают основную структуру.
5. Заголовок задачи должен читаться первым, метаданные — вторыми, результат — третьим уровнем.
6. При большом количестве задач экран должен оставаться сканируемым.
7. Мобильная версия не должна требовать горизонтального скролла для обычных карточек.

## Первый кодовый шаг

Изменить только визуальный слой через CSS:

- сделать карточки задач на Главной и в списке задач компактнее;
- уменьшить вертикальные отступы внутри карточек;
- сделать кнопки действий меньше и визуально спокойнее;
- снизить интенсивность теней;
- улучшить контраст заголовка, метаданных и результата;
- сделать блок «Просрочено» визуально отличимым, но не тревожным;
- выровнять плотность блоков Главной;
- улучшить адаптацию карточек на узких экранах.

## Что не меняется

- `state` и пользовательские данные;
- `localStorage` и Data Store;
- модель задачи;
- route id;
- `renderDashboard()` и `taskRow()`;
- обработчики кнопок;
- импорт и экспорт;
- структура других экранов;
- цветовая тема целиком.

## Проверка

Перед объединением необходимо проверить:

- `node --check app.js`;
- `node --check core/storage/data-store.js`;
- `node --check core/models/task.js`;
- `git diff --check`;
- в рабочем diff нет изменений JavaScript;
- изменены только `styles.css`, `index.html` и этот документ;
- cache-busting `styles.css` обновлён;
- после публикации визуально проверить Главную и экран «Задачи» в браузере.
