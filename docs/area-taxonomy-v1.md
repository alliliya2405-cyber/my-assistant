# Единая классификация сфер задач

В интерфейсе используются только три сферы:

- **Профессиональное** — задачи проектов и профессиональные задачи.
- **Образовательное** — задачи обучения и материалы раздела «Образование».
- **Личное** — личные задачи, включая здоровье и досуг.

Старые значения (`Профессиональная`, `Образовательная`, `Личная`, `Здоровье`, `Досуг`) нормализуются в эти три значения без удаления задач.
