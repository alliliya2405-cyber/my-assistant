# 1. Что это за проект

«Мой ассистент» — персональное веб-приложение для организации задач и дальнейшего развития функций личного цифрового ассистента.

Проект развивается небольшими законченными этапами без переписывания работающих частей без необходимости.

---

# 2. Стабильная версия

Стабильная контрольная версия находится в ветке `main`.

В `main` находятся:

- Architecture v2;
- единая модель задачи `core/models/task.js`;
- Data Model v1;
- Data Store Design v1;
- минимальный `core/storage/data-store.js`;
- начальное чтение состояния через `MyAssistantDataStore.load()`;
- сохранение состояния через `MyAssistantDataStore.save(state)`.

# 5. Принятые решения

- Data Store подключается постепенно, маленькими проверяемыми шагами.
- Начальное чтение и обычное сохранение уже идут через Data Store.
- Ключ `myAssistantProFinal.v1` и JSON-формат сохраняются без изменений.
- Импорт, экспорт и резервная копия импорта пока остаются по прежней схеме.
- До дальнейшего изменения хранения нужно проверить сохранение на опубликованной версии с реальными пользовательскими данными.
- После успешной проверки сохранения можно переключаться с технического фундамента на этап Application UX / Structure v1; дальнейший рефакторинг хранения выполнять только по необходимости.

---

# 6. Над чем работаем сейчас

Изменение `persist(...)` уже находится в `main`.

Текущая контрольная задача — подтвердить в опубликованном приложении, что изменение реальных данных сохраняется после перезагрузки страницы и существующие данные остаются на месте.

---

# 7. Следующее одно действие

**в опубликованном приложении изменить одну безопасную запись (например, создать тестовую задачу или изменить существующую), обновить страницу и убедиться, что изменение сохранилось.**

Если изменение сохраняется и остальные данные на месте, этап Data Store save v1 считается полностью проверенным.

После этого следующий большой этап — **Application UX / Structure v1: анализ текущего интерфейса и проектирование новой структуры приложения до внесения визуальных изменений в код**.

Если после перезагрузки изменение пропадает или данные повреждаются, дальнейшие изменения останавливаются и сначала исправляется сохранение.

---

# 8. Что пока не менять

Пока не менять:

- интерфейс приложения до завершения контрольной проверки сохранения;
- импорт и экспорт;
- резервную копию импорта;
- ключ `myAssistantProFinal.v1`;
- формат `localStorage`;
- `normalize(...)`;
- `sample()`;
- `core/models/task.js`;
- пользовательские данные массовыми преобразованиями;
- способ хостинга.

---

# 9. Что отложено на потом

После контрольной проверки сохранения:

- начать Application UX / Structure v1;
- изучить текущую структуру экранов и навигации;
- предложить новую информационную архитектуру простым языком;
- после согласования постепенно менять интерфейс и дизайн.

Отдельно, только когда это станет необходимо:

- перевести резервную копию импорта на Data Store;
- проверить импорт и восстановление резервной копии;
- продолжать развитие слоя данных без лишнего рефакторинга.
