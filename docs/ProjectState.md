# 1. Что это за проект

«Мой ассистент» — персональный цифровой планнер и цифровой ассистент для ежедневной работы с задачами, проектами, планированием, знаниями и личными областями жизни.

Проект развивается небольшими законченными этапами с обязательной проверкой и защитой пользовательских данных.

Data Store проверен на реальных пользовательских данных: существующие и новые/изменённые задачи сохраняются после перезагрузки.

Application UX navigation v1 и Главная / Сегодня v1 опубликованы и визуально подтверждены пользователем.

Design System v1 — task density объединён с `main` через Pull Request #9.

Task Card Unified v1 объединён с `main` через Pull Request #10 и визуально проверен пользователем.

Top Bar & Quick Actions v1 объединён с `main` через Pull Request #11 и визуально проверен пользователем.

Project Cards v1 объединён с `main` через Pull Request #12. Пользовательская проверка показала, что новый вид карточек загрузился, редактирование проекта открывается корректно, но у раскрытого проекта обнаружена вложенная вертикальная прокрутка.

Project Scroll Fix v1 выполнен отдельным безопасным этапом и объединён с `main` через Pull Request #13. Исправление отключает внутреннюю вертикальную прокрутку `.project-details`, чтобы раскрытый проект прокручивался вместе со страницей. `app.js`, данные, Data Store, маршруты и логика проектов не менялись.

---

# 4. Принятые решения

- UX меняется постепенно без удаления существующих функций;
- дизайн-система развивается от плотности, читаемости и иерархии;
- визуальные дефекты после пользовательской проверки исправляются до перехода к следующему этапу;
- route id, пользовательские данные, Data Store и бизнес-логика сохраняются, пока нет отдельной причины их менять;
- карточки проектов должны использовать обычную прокрутку страницы, а не отдельный вертикальный скролл внутри раскрытой карточки.

---

# 5. Над чем работаем сейчас

Project Scroll Fix v1 уже находится в `main`.

Текущая контрольная задача — визуально проверить, что у раскрытого проекта исчезла отдельная вертикальная полоса прокрутки внутри карточки и всё содержимое проекта доступно через обычную прокрутку страницы.

---

# 6. Следующее одно действие

**после публикации открыть «Проекты», развернуть проект с большим содержимым и убедиться, что внутри карточки больше нет отдельного вертикального скролла.**

Если проверка успешна, этап экрана «Проекты» считается завершённым и можно выбрать следующий ключевой экран для дизайн-системы.

---

# 7. Что пока не менять

До пользовательской проверки Project Scroll Fix v1 не менять:

- пользовательские данные;
- Data Store и формат `localStorage`;
- `core/models/task.js`;
- route id;
- бизнес-логику задач, проектов и календарей;
- импорт и экспорт;
- другие экраны массовыми изменениями;
- способ хостинга.

---

# 8. Что отложено на потом

После успешной проверки экрана проектов:

- распространить дизайн-систему на другие основные экраны;
- отдельно решить перенос импорта/экспорта из постоянного footer в настройки;
- при необходимости улучшить глобальный поиск и сервисное меню.

Отдельно по необходимости:

- перевод резервной копии импорта на Data Store;
- проверка импорта и восстановления;
- сервер и синхронизация между устройствами только при появлении реальной потребности.
