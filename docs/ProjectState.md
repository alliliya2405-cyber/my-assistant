# 1. Что это за проект

«Мой ассистент» — персональный цифровой планнер и цифровой ассистент для ежедневной работы с задачами, проектами, планированием, знаниями и личными областями жизни.

Проект развивается небольшими законченными этапами с обязательной проверкой и защитой пользовательских данных.

# 4. Принятые решения

- проект развивается по одному небольшому завершённому шагу;
- исправлять причину, а не маскировать симптом;
- данные и Data Store не менять для чисто визуальных этапов;
- не продолжать полировку уже удобного состояния без конкретной пользовательской проблемы;
- завершённые экраны раздела «Проекты» больше не менять без отдельной причины;
- после завершения раздела «Проекты» следующей областью выбрать **«Главную»**, потому что это центральный ежедневный вход в приложение и он связывает планирование, задачи и проекты;
- сначала провести визуальную оценку опубликованной «Главной», затем выбрать только одну конкретную проблему для следующего этапа;
- не переносить автоматически решения из экранов «Проекты» на «Главную»: оценивать её как отдельный пользовательский сценарий.

# 7. Что пока не менять

Без отдельной продуктовой причины не менять:

- пользовательские данные;
- Data Store и формат `localStorage`;
- `core/models/task.js`;
- `app.js`;
- проектную и календарную бизнес-логику;
- автоматические связанные задачи;
- route id;
- завершённые экраны раздела «Проекты»;
- структуру данных отчётов;
- генерацию Word;
- правила импорта CSV/JSON;
- правила формирования сводного документа отдела;
- расчёт и проверку 100% распределения времени;
- разделы «Жизнь», «Знания» и «Ещё», пока не появится конкретная новая проблема.

---

# 8. Что отложено на потом

После отдельной проверки «Главной» определить, требуется ли один небольшой UX/UI-этап или экран уже достаточно удобен.

Сервер и синхронизацию между устройствами рассматривать только при реальной потребности.
