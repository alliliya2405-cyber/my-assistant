# 1. Что это за проект

«Мой ассистент» — персональный цифровой планнер и цифровой ассистент для ежедневной работы с задачами, проектами, планированием, знаниями и личными областями жизни.

Проект развивается небольшими законченными этапами с обязательной проверкой и защитой пользовательских данных.

Экран «Жизнь → Семья» визуально подтверждён пользователем 11.08.2026 после исправлений PR #27 и #28:

- три семейных раздела видны сразу;

- название и описание записи занимают всю ширину карточки;

Education Cards v1 объединён с `main` через Pull Request #29. Этап меняет только визуальную структуру «Жизнь → Образование» и UI-guard от универсального collapse:

- четыре раздела «Философия / МГУ», «Книги», «Вебинары», «Курсы» выстраиваются в сбалансированную сетку 2×2;
- записи внутри карточек используют полноширинный текст и отдельную строку действий;
- на узком экране сетка становится одноколоночной;
- карточки не должны превращаться в «Нажмите, чтобы открыть»;
- `app.js`, `renderLife()`, данные, Data Store и обработчики не менялись.

---

# 4. Принятые решения

- исправлять подтверждённую причину, а не маскировать симптом;
- избегать вложенной вертикальной прокрутки там, где экран может расти в обычном потоке страницы;
- не дублировать существующую бизнес-логику;
- универсальный collapse не должен скрывать ключевые карточки экранов «Здоровье», «Семья» и «Образование»;
- текст записи важнее технических действий и должен получать полноценную ширину;
- данные и Data Store не менять для чисто визуальных этапов;
- раздел «Жизнь» дорабатывается последовательно: Здоровье → Семья → Образование → Досуг.
