# 1. Что это за проект

«Мой ассистент» — персональный цифровой планнер и цифровой ассистент для ежедневной работы с задачами, проектами, планированием, знаниями и личными областями жизни.

Проект развивается небольшими законченными этапами с обязательной проверкой и защитой пользовательских данных.

# 4. Принятые решения

- `stable-v1` остаётся неподвижной контрольной точкой первой стабильной версии;
- дальнейшая разработка идёт в `main` только по реальным проблемам и потребностям эксплуатации;
- пользовательские данные и формат существующего `localStorage` без отдельной необходимости не мигрировать;
- потенциально разрушительные массовые действия всегда требуют явного подтверждения;
- «Удалить всё» не должно незаметно удалять скрытые фильтром задачи;
- автоматически связанные задачи не удалять напрямую;
- фильтры областей должны работать и в списке, и в Kanban;
- скрытие блока «Спринты проекта» не должно удалять данные проекта или подпроектов;
- пользователь должен иметь возможность вернуть скрытый блок;
- по подтверждённому запросу пользователя задачи «Ходьба», «Вода», «Капли в глаза» не должны регенерироваться после удаления.

# 7. Что пока не менять

Без конкретной эксплуатационной причины не менять:

- контрольную ветку `stable-v1`;
- пользовательские данные массово, кроме явно подтверждённых пользователем операций;
- ключ хранения `myAssistantProFinal.v1` и формат основной структуры `localStorage`;
- `core/models/task.js`;
- основную бизнес-логику проектов, совещаний, отчётов и связанных задач;
- завершённые экраны только ради косметической полировки;
- сервер и синхронизацию между устройствами до появления реальной необходимости.

---

# 8. Что отложено на потом

- сервер;
- защищённая база данных;
- синхронизация между устройствами;
- новая функциональность, которая не возникла из реального сценария использования.
