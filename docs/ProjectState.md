# 1. Что это за проект

«Мой ассистент» — персональное веб-приложение для организации задач и дальнейшего развития функций личного цифрового ассистента.

Проект развивается небольшими законченными этапами без переписывания работающих частей без необходимости.

---

# 2. Стабильная версия

Стабильная контрольная версия находится в ветке `main`.

В `main` внедрены:

- Architecture v2;
- единая модель задачи `core/models/task.js`;
- завершённая и проверенная документация модели данных `docs/DataModel.md`.

Для задач стабильно поддерживаются статусы:

- `planned`;
- `done`.

Проверены создание, изменение, завершение, повторное открытие и локальное сохранение задач.

# 5. Принятые решения

- Стабильная модель задачи является исходной точкой для будущего слоя данных, а не заменяется новым несовместимым форматом.
- На текущем этапе используются только статусы задач `planned` и `done`.
- Существующий `localStorage` остаётся действующим механизмом хранения до отдельного этапа.
- Будущий единый слой данных должен сохранять существующие пользовательские данные и совместимость.
- `localStorage` нельзя очищать как способ миграции.
- Подпроекты, спринты, команда и строки отчётов пока могут оставаться вложенными структурами.
- Серверная база данных не добавляется без реальной необходимости.

# 8. Что пока не менять

Пока не менять без отдельного следующего этапа:

- существующий работающий интерфейс;
- рабочую логику приложения, не относящуюся к слою данных;
- существующий формат и содержимое `localStorage`;
- стабильную модель задач `core/models/task.js`;
- структуру Architecture v2;
- пользовательские данные;
- способ хостинга приложения.

---

# 9. Что отложено на потом

После проектирования единого слоя данных можно рассматривать:

- его реализацию поверх текущего `localStorage`;
- безопасную миграцию существующего формата при необходимости;
- постепенный перевод разделов приложения на единый слой данных;
- расширение статусов и сущностей только по продуктовой необходимости;
- синхронизацию между устройствами;
- серверное хранение, когда для него появится реальная необходимость;
- дальнейшие функции цифрового ассистента.
