# 1. Что это за проект

«Мой ассистент» — персональное веб-приложение для организации задач и дальнейшего развития функций личного цифрового ассистента.

Проект развивается небольшими законченными этапами без переписывания работающих частей без необходимости.

---

В `main` находятся:

---

# 5. Принятые решения

- Data Store подключается постепенно, небольшими проверяемыми шагами.
- Начальное чтение уже переведено на Data Store.
- Сохранение через `persist(...)` пока не переводится на Data Store до пользовательской проверки опубликованной версии.
- Импорт, экспорт и резервные копии пока не меняются.
- `normalize(...)`, `sample()`, модель задач и формат JSON остаются прежними.
- Успешная публикация GitHub Pages сама по себе не заменяет проверку реальных пользовательских данных.

---

# 6. Над чем работаем сейчас

Изменение начального чтения находится в `main` и опубликовано через GitHub Pages.

Текущая контрольная задача — подтвердить в браузере пользователя, что существующие задачи и проекты открываются без изменений после обновления страницы.

---

# 7. Следующее одно действие

**в браузере открыть опубликованное приложение, обновить страницу без старого кэша и убедиться, что существующие задачи и проекты на месте.**

Если данные отображаются как раньше, этап начального чтения через Data Store считается полностью проверенным и следующим отдельным шагом можно переводить `persist(...)` на `MyAssistantDataStore.save(state)`.

Если данные исчезли, подменились тестовыми или появилась ошибка загрузки, дальнейшее развитие Data Store останавливается и сначала исправляется эта проблема.

---

- интерфейс приложения;
- `persist(...)`;
- импорт и экспорт;
- ключ `myAssistantProFinal.v1`;
- формат `localStorage`;
- `normalize(...)`;
- `sample()`;
- `core/models/task.js`;

- способ хостинга.

---

# 9. Что отложено на потом

После успешной пользовательской проверки опубликованной версии отдельно выполнять:

- перевод `persist(...)` на `MyAssistantDataStore.save(state)`;
- проверку сохранения после перезагрузки;
- перевод резервной копии импорта на Data Store;
- проверку импорта и восстановления резервной копии;
- дальнейшее развитие слоя данных только по необходимости.
