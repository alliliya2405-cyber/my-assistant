# 1. Что это за проект

«Мой ассистент» — персональный цифровой планнер и цифровой ассистент для ежедневной работы с задачами, проектами, планированием, знаниями и личными областями жизни.

Проект развивается небольшими законченными этапами с обязательной визуальной проверкой и защитой пользовательских данных.

---

# 2. Стабильная версия

Стабильная контрольная версия находится в ветке `main`.

В `main` находятся Architecture v2, Data Model v1, Data Store v1, Application UX navigation v1, основные этапы дизайн-системы для Главной, задач, проектов и планирования, завершённые визуальные этапы раздела «Жизнь», а также подтверждённые экраны «Знания → Заметки», «Библиотека» и «Рефлексия».

Последние подтверждённые этапы:

- Health Habit Cards v1 + Health Collapse Fix v1;
- Family Cards v1 + Family Layout Fix v1/v2;
- Education Cards v1;
- Leisure Cards v1 + Leisure Collapse Fix v1;
- Notes Cards v1 + Notes Collapse Fix v1;
- Library Cards v1 + усиленный Library guard;
- Reflection Cards v1 + Reflection Collapse Fix v2.

---

# 3. Что завершено и проверено

Основные экраны «Главная», «Задачи», «Проекты», «Сегодня», «Неделя» и «Месяц» проверены пользователем на опубликованной версии.

Раздел «Жизнь» завершён и визуально подтверждён пользователем:

- «Здоровье» — привычки раскрыты сразу, ежедневное действие видно, лишний collapse устранён;
- «Семья» — текст записей читается нормальными строками, действия не сжимают содержимое;
- «Образование» — четыре раздела отображаются сбалансированной сеткой 2×2, карточки раскрыты и читаемы;
- «Досуг» — карточка отображается без лишней collapse-шапки и без глобальных кнопок.

Раздел «Знания» подтверждён пользователем частично:

- «Заметки» — чистая раскрытая карточка без универсального collapse;
- «Библиотека» — чистая раскрытая карточка материала без лишней collapse-шапки;
- «Рефлексия» — одна карточка без дублирующей шапки; «Следующий шаг» выделен как практический итог.

При визуальных этапах пользовательские данные, Data Store и бизнес-логика не менялись.

---

# 4. Принятые решения

- исправлять подтверждённую причину, а не маскировать симптом;
- избегать вложенной вертикальной прокрутки там, где экран может расти в обычном потоке страницы;
- не дублировать существующую бизнес-логику;
- универсальный collapse не должен скрывать ключевые пользовательские карточки;
- текст и содержимое записи важнее технических действий;
- данные и Data Store не менять для чисто визуальных этапов;
- для «Доски» сохранить рабочее большое поле и улучшать прежде всего панель инструментов, а не саму модель доски;
- для «Цитат дня» сохранить существующие фильтры и действия, убрав только лишнее универсальное сворачивание и улучшив сетку.
