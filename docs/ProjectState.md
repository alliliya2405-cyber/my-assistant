# 1. Что это за проект

# 4. Принятые решения

- `stable-v1` остаётся неподвижной контрольной точкой первой стабильной версии;
- дальнейшая разработка идёт в `main` только по реальным проблемам и потребностям эксплуатации;
- пользовательские данные и формат существующего `localStorage` без отдельной необходимости не мигрировать;
- потенциально разрушительные массовые действия всегда требуют явного подтверждения;
- «Удалить всё» в отфильтрованном списке не должно незаметно удалять скрытые фильтром задачи;
- автоматически связанные задачи не удалять напрямую, чтобы источник не создавал их повторно и не нарушались связи данных;
- удаление отдельного будущего экземпляра привычки должно означать пропуск именно этой даты, а не удаление самой привычки;
- перед потенциально опасным изменением пользователь может сделать резервную копию через «Экспорт».

# 6. Следующее одно действие

**после публикации GitHub Pages открыть экран «Задачи» и визуально проверить, что у задач появилась кнопка «Удалить», а у заголовка группы «Позже» — «Удалить всё». Для функциональной проверки безопасно удалить одну ненужную будущую задачу и убедиться, что после обновления страницы она не возвращается.**

Кнопку «Удалить всё» не использовать как тест, если пользователь действительно не хочет удалить все показанные будущие задачи.

---

# 7. Что пока не менять

Без конкретной эксплуатационной причины не менять:

- контрольную ветку `stable-v1`;
- пользовательские данные массово;
- ключ хранения `myAssistantProFinal.v1` и формат основной структуры `localStorage`;
- `core/models/task.js`;
- основную бизнес-логику проектов, совещаний, отчётов и связанных задач;
- завершённые экраны только ради косметической полировки;
- сервер и синхронизацию между устройствами до появления реальной необходимости.
