# 1. Что это за проект

«Мой ассистент» — персональный цифровой планнер и цифровой ассистент для ежедневной работы с задачами, проектами, планированием, знаниями и личными областями жизни.

Проект развивается небольшими законченными этапами с обязательной проверкой и защитой пользовательских данных.

---

# 2. Стабильная версия

Стабильная контрольная версия находится в ветке `main`.

В `main` находятся:

- Architecture v2;
- единая модель задачи `core/models/task.js`;

# 4. Принятые решения

- информационная архитектура Application UX / Structure v1 утверждена пользователем;
- UX меняется постепенно без удаления существующих функций;
- route id и render-функции сохраняются, пока нет отдельной причины их менять;
- дальнейший рефакторинг Data Store не является текущим приоритетом;
- импорт, экспорт и резервная копия импорта пока остаются по прежней схеме;
- визуальный дизайн карточек и форм будет меняться отдельными этапами после проверки новой структуры навигации.

**после публикации GitHub Pages открыть приложение и проверить новую боковую навигацию: Главная открывается, разделы раскрываются по одному, а все привычные экраны доступны внутри новых групп.**

Следующим отдельным этапом после этого будет проектирование и улучшение экрана **Главная / Сегодня**.

Если обнаружена проблема навигации, дальнейшая UX-разработка останавливается и сначала исправляется эта проблема.

- цвета и общую дизайн-систему.
