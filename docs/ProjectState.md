# 4. Принятые решения

- раздел «Проекты» дорабатывать по одному экрану и принимать каждый шаг отдельно;
- исправлять причину, а не маскировать симптом;
- данные и Data Store не менять для чисто визуальных этапов;
- не продолжать полировку уже удобного состояния без конкретной пользовательской проблемы;
- на экране «Команда» верхние действия и пояснения воспринимаются как единый управляющий блок;
- внутри карточки участника визуально разделять данные человека, участие в проектах и поручения;
- форму поручения улучшать отдельно от бизнес-логики поручений: компактность модального окна не должна менять поля или сохранение данных.

# 5. Над чем работаем сейчас

Текущий рабочий экран — **«Проекты → Команда»**.

Текущий этап — **Assignment Modal Compact v1**.

Первая пользовательская проверка 15.08.2026 показала частичный результат: нижняя кнопка «Сохранить» остаётся доступной, но два textarea всё ещё занимают слишком большую высоту и внутри формы сохраняется лишняя вертикальная прокрутка.

Причина — базовые стили textarea перекрывают первоначальное визуальное уплотнение. В `main` внесена вторая безопасная версия CSS:

- для `brief` и `criteria` заданы более конкретные селекторы и принудительная стартовая высота 72 px;
- при низком экране стартовая высота уменьшается до 62 px;
- поля ввода и select слегка уплотнены;
- внутренние отступы модального окна уменьшены;
- лишнее служебное пространство снизу скрыто;
- textarea по-прежнему можно растягивать вручную;
- логика формы, поля, валидация, сохранение, `app.js`, пользовательские данные и Data Store не менялись.

Версия `styles/assignment-modal-compact-v1.css` в `index.html` обновлена до `v=2` для обхода старого кэша.

Рабочая версия: `main`.

# 7. Что пока не менять

Без отдельной продуктовой причины не менять:

- пользовательские данные;
- Data Store и формат `localStorage`;
- `core/models/task.js`;
- `app.js`;
- проектную и календарную бизнес-логику;
- автоматические связанные задачи;
- route id;
- завершённые экраны «Совещания» и «Все проекты»;
- внутреннюю логику ролей, участия в проектах и поручений на экране «Команда»;
- вопрос отсутствующих проектных привязок у отдельных карточек участников — проверить отдельным логическим этапом после завершения модального окна;
- «Ресурсную карту» и «Отчёты» до их отдельного этапа.
