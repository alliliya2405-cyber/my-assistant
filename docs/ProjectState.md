# 1. Что это за проект

«Мой ассистент» — персональный цифровой планнер и цифровой ассистент для ежедневной работы с задачами, проектами, планированием, знаниями и личными областями жизни.

Проект развивается небольшими законченными этапами с обязательной проверкой и защитой пользовательских данных.

---

# 2. Стабильная версия

Стабильная контрольная версия находится в ветке `main`.

В `main` находятся:

- Architecture v2;
- единая модель задачи `core/models/task.js`;
- Data Model v1;
- Data Store v1;
- Application UX navigation v1;
- Главная / Сегодня v1;
- Design System v1 — task density;
- Task Card Unified v1 после Pull Request #10;
- Top Bar & Quick Actions v1 после Pull Request #11;
- документация UX и дизайн-системы в `docs/`.

---

# 3. Что завершено и проверено

Data Store проверен на реальных пользовательских данных: существующие и новые/изменённые задачи сохраняются после перезагрузки.

Application UX navigation v1 и Главная / Сегодня v1 опубликованы и визуально подтверждены пользователем.

Design System v1 — task density объединён с `main` через Pull Request #9.

Task Card Unified v1 объединён с `main` через Pull Request #10 и визуально проверен пользователем: раскрытая задача выглядит как единая карточка, редактирование открывается корректно.

Top Bar & Quick Actions v1 выполнен в отдельной ветке `top-bar-quick-actions-v1` и объединён с `main` через Pull Request #11.

Пользовательская проверка 11.08.2026 подтвердила, что глобальное действие «Быстро добавить» открывает существующее окно «Что добавить?» с выбором типа записи. На скриншоте корректно отображаются выбор типа записи, поле проекта для участника, кнопки «Отмена» и «Сохранить», а также закрытие окна.

На этапе Top Bar & Quick Actions v1:

- статус сохранения оформлен как небольшой системный индикатор;
- глобальная кнопка «Быстро добавить» сохранена;
- локальные действия экранов сохранены;
- `app.js`, обработчик `openQuickAdd()`, Data Store, модели, маршруты и пользовательские данные не менялись;
- изменение изолировано в `styles/top-bar-quick-actions-v1.css` и подключении в `index.html`;
- проект решения зафиксирован в `docs/TopBarQuickActionsV1.md`.

Top Bar & Quick Actions v1 считается завершённым и проверенным.

# 4. Принятые решения

- UX меняется постепенно без удаления существующих функций;
- дизайн-система развивается от плотности, читаемости и иерархии;
- визуальные дефекты после пользовательской проверки исправляются до перехода к следующему этапу;
- route id, пользовательские данные, Data Store и бизнес-логика сохраняются, пока нет отдельной причины их менять;
- глобальное «Быстро добавить» дополняет, а не заменяет локальные действия конкретного экрана;
- Top Bar & Quick Actions v1 считается проверенным;
- следующий отдельный визуальный этап — экран проектов.

# 7. Что пока не менять

На следующем визуальном этапе не менять без отдельной причины:

- пользовательские данные;
- Data Store и формат `localStorage`;
- `core/models/task.js`;
- route id;
- бизнес-логику задач, проектов и календарей;
- импорт и экспорт;
- другие экраны массовыми изменениями;
- способ хостинга.

---

# 8. Что отложено на потом

- распространить дизайн-систему на другие основные экраны;
- отдельно решить перенос импорта/экспорта из постоянного footer в настройки;
- при необходимости улучшить глобальный поиск и сервисное меню.

Отдельно по необходимости:

- сервер и синхронизация между устройствами только при появлении реальной потребности.
