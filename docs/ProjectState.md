# 1. Что это за проект

«Мой ассистент» — персональный цифровой планнер и цифровой ассистент для ежедневной работы с задачами, проектами, планированием, знаниями и личными областями жизни.

Проект развивается небольшими законченными этапами с обязательной проверкой и защитой пользовательских данных.

# 3. Что завершено и проверено

Data Store проверен на реальных пользовательских данных.

Application UX navigation v1, Главная / Сегодня v1, Task Card Unified v1, Top Bar & Quick Actions v1, экран «Проекты», Planning / Today Density v1 и Planning / Week Density v1 опубликованы и визуально подтверждены пользователем.

Planning / Month Clarity v1 объединён с `main` через Pull Request #17. Пользовательский скриншот подтвердил, что пустые дни стали спокойнее, а дни с задачами заметнее.

На последующей проверке выявлено два дефекта месяца:

- универсальный механизм сворачивания ошибочно оборачивал всю карточку календаря, брал название первой задачи как заголовок и показывал «Свернуть»;
- строка «Все задачи» была обычным `span` и не имела действия.

Month Collapse Fix v1 через CSS оказался недостаточным и не закрыл первый дефект.

Month Interactions Fix v2 выполнен в отдельной ветке и объединён с `main` через Pull Request #19. Исправление:

- после рендера месяца снимает универсальный collapse только с `.month-calendar-card` и удаляет ошибочную collapse-панель;
- превращает строку «Все задачи» в реальную кнопку;
- кнопка «Все задачи» открывает общий экран «Задачи» через уже существующую навигацию;
- данные, Data Store и бизнес-логика задач не меняются.

PR #19 перед объединением имел `mergeable: true` и успешно объединён с `main`.

Требуется пользовательская проверка опубликованной версии.

# 4. Принятые решения

- UX меняется постепенно без удаления существующих функций;
- не дублировать уже существующую бизнес-логику;
- обычные задачи имеют понятное удаление в «Дне» и «Неделе»;
- автоматически связанные задачи удаляются через их источник;
- пустые календарные дни должны оставаться доступными для планирования, но не конкурировать с днями, где есть задачи;
- универсальное сворачивание не должно применяться к целой месячной календарной карточке;
- строка «Все задачи» должна быть реальным действием и открывать общий экран задач;
- route id, пользовательские данные и Data Store не менять без отдельной необходимости.
