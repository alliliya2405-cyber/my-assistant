# 1. Что это за проект

«Мой ассистент» — персональное веб-приложение для организации задач и дальнейшего развития функций личного цифрового ассистента.

Проект развивается небольшими законченными этапами без переписывания работающих частей без необходимости.

---

# 2. Стабильная версия

Стабильная контрольная версия находится в ветке `main`.

В `main` находятся:

- Architecture v2;
- единая модель задачи `core/models/task.js`;
- Data Model v1 в `docs/DataModel.md`;
- проект Data Store v1 в `docs/DataStoreDesign.md`;
- минимальная реализация Data Store v1 в `core/storage/data-store.js`.

Работающий интерфейс и существующий формат пользовательских данных не изменены.

# 4. Что проверено

Data Store проверен изолированно с тестовым объектом `localStorage`.

Проверено:

- пустое хранилище возвращает `null`;
- сохранение и последующее чтение возвращают эквивалентный объект;
- основной ключ остаётся `myAssistantProFinal.v1`;
- резервная копия `beforeImport` использует прежний ключ;
- резервная копия читается обратно;
- повреждённый JSON приводит к ошибке и не маскируется;
- пустое имя резервной копии отклоняется.

Изолированный тест завершён успешно.

Pull Request #4 имел состояние `mergeable: true`, `mergeable_state: clean` и успешно объединён с `main`.

Поскольку модуль ещё не подключён к приложению, пользовательский интерфейс и существующие пользовательские данные этим этапом не затронуты.

---

# 5. Принятые решения

- Data Store остаётся тонким слоем физического хранения.
- Основной ключ `myAssistantProFinal.v1` не меняется.
- Формат JSON не меняется.
- Data Store не выполняет `normalize(...)` и не создаёт `sample()`.
- Data Store не содержит UI-логику и не скрывает ошибки чтения/записи.
- Модуль публикуется как `window.MyAssistantDataStore`.
- Подключение к приложению выполняется постепенно, отдельными проверяемыми шагами.
- Не переводить одновременно загрузку, сохранение и импорт на новый слой.
