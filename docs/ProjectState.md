# 1. Что это за проект

«Мой ассистент» — персональный цифровой планнер и цифровой ассистент для ежедневной работы с задачами, проектами, планированием, знаниями и личными областями жизни.

Проект развивается небольшими законченными этапами с обязательной проверкой и защитой пользовательских данных.

# 4. Принятые решения

- проект развивается по одному небольшому завершённому шагу;
- исправлять причину, а не маскировать симптом;
- данные и Data Store не менять для чисто визуальных этапов;
- не продолжать полировку уже удобного состояния без конкретной пользовательской проблемы;
- завершённые экраны раздела «Проекты» больше не менять без отдельной причины;
- следующая рабочая область после «Проектов» — **«Главная»**;
- Главная должна в первую очередь отвечать на вопрос «что делать сегодня», а просрочка должна оставаться заметной, но не перехватывать главный визуальный приоритет;
- для визуальных этапов Главной не менять данные, `app.js`, бизнес-логику задач и проектов;
- после подтверждения Home Daily Focus v1 не продолжать косметическую полировку Главной без отдельной конкретной проблемы.
