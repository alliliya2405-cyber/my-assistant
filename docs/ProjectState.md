# 1. Что это за проект

«Мой ассистент» — персональный цифровой планнер и цифровой ассистент для ежедневной работы с задачами, проектами, планированием, знаниями и личными областями жизни.

Проект развивается небольшими законченными этапами с обязательной проверкой и защитой пользовательских данных.

---

# 2. Стабильная версия

Стабильная контрольная версия находится в ветке `main`.

В `main` находятся:

- Architecture v2;
- единая модель задачи `core/models/task.js`;

# 4. Принятые решения

- информационная архитектура Application UX / Structure v1 утверждена пользователем;
- UX меняется постепенно без удаления существующих функций;
- Главная становится рабочим центром текущего дня, а не витриной всех показателей;
- задачи на сегодня имеют первый приоритет, просрочка показывается спокойно и отдельно;
- активные проекты и ближайшие события должны быть видны на Главной;
- route id и бизнес-логика сохраняются, пока нет отдельной причины их менять;
- дальнейший рефакторинг Data Store не является текущим приоритетом;
- импорт, экспорт и резервная копия импорта пока остаются по прежней схеме.

# 7. Что пока не менять

До пользовательской проверки новой Главной не менять:

- пользовательские данные;
- Data Store и формат `localStorage`;
- `core/models/task.js`;
- route id;
- бизнес-логику задач, проектов и календарей;
- импорт и экспорт;
- другие экраны массовыми изменениями;
- способ хостинга.
