# 1. Что это за проект

«Мой ассистент» — персональный цифровой планнер и цифровой ассистент для ежедневной работы с задачами, проектами, планированием, знаниями и личными областями жизни.

Проект развивается небольшими законченными этапами с обязательной проверкой и защитой пользовательских данных.

# 4. Принятые решения

- раздел «Проекты» дорабатывать по одному экрану и принимать каждый шаг отдельно;
- исправлять причину, а не маскировать симптом;
- данные и Data Store не менять для чисто визуальных этапов;
- не продолжать полировку уже удобного состояния без конкретной пользовательской проблемы;
- верх ресурсной карты должен быстро давать сводку, но не отнимать слишком много места у главной рабочей части — карточек сотрудников;
- четыре сводных показателя и их кликабельность сохраняются;
- внутри карточки сотрудника визуально отделять шапку человека и уровень нагрузки от рабочих метрик, ближайшего срока, проектов и поручений;
- расчёт нагрузки, правила просрочки, кликабельность метрик и действия с поручениями не менять для визуального этапа;
- после подтверждения Resource Person Hierarchy v1 ресурсную карту считать завершённой и без отдельной пользовательской проблемы больше не полировать.
