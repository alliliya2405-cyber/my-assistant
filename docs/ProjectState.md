# 1. Что это за проект

«Мой ассистент» — персональный цифровой планнер и цифровой ассистент для ежедневной работы с задачами, проектами, планированием, знаниями и личными областями жизни.

Проект развивается небольшими законченными этапами с обязательной проверкой и защитой пользовательских данных.

Проверено, что удаление обычной задачи:

- доступно в календарной карточке;
- требует подтверждения;
- удаляет задачу из единого списка задач;
- сохраняется после обновления страницы;
- корректно отражается в связанных представлениях «Сегодня» и «Неделя».

Автоматически связанные задачи с `generatedLinked` по-прежнему не удаляются напрямую из календарной карточки, потому что ими управляет источник.

Calendar Task Delete v1 считается завершённым.

# 4. Принятые решения

- UX меняется постепенно без удаления существующих функций;
- не дублировать уже существующую бизнес-логику;
- обычные задачи имеют понятное удаление в «Дне» и «Неделе»;
- удаление обязательно требует подтверждения;
- автоматически связанные задачи удаляются через их источник;
- route id, пользовательские данные и Data Store не менять без отдельной необходимости;
- следующий визуальный этап — экран «Планирование → Месяц».
