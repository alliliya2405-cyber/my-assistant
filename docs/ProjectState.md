# 1. Что это за проект

«Мой ассистент» — персональный цифровой планнер и цифровой ассистент для ежедневной работы с задачами, проектами, планированием, знаниями и личными областями жизни.

Проект развивается небольшими законченными этапами с обязательной проверкой и защитой пользовательских данных.

# 4. Принятые решения

- раздел «Проекты» дорабатывать по одному экрану и принимать каждый шаг отдельно;
- исправлять причину, а не маскировать симптом;
- данные и Data Store не менять для чисто визуальных этапов;
- не продолжать полировку уже удобного состояния без конкретной пользовательской проблемы;
- экран «Отчёты» показывает основной рабочий сценарий последовательно: персональные документы → сводный документ отдела → работа с готовым документом;
- ручной ввод, импорт, шаблоны и проверка настроек остаются доступными, но визуально не конкурируют с основным сценарием;
- форматы документов, генерацию Word, данные, правила интеграции и существующую бизнес-логику отчётов для визуального этапа не менять;
- подтверждённый верх экрана «Отчёты» без конкретной новой проблемы больше не полировать.

# 7. Что пока не менять

Без отдельной продуктовой причины не менять:

- пользовательские данные;
- Data Store и формат `localStorage`;
- `core/models/task.js`;
- `app.js`;
- проектную и календарную бизнес-логику;
- автоматические связанные задачи;
- route id;
- завершённые экраны «Совещания», «Все проекты», «Команда» и «Ресурсная карта»;
- структуру данных отчётов;
- генерацию Word;
- правила импорта CSV/JSON;
- правила формирования сводного документа отдела;
- подтверждённую верхнюю зону «Шаг 1 → Шаг 2 → Шаг 3» экрана «Отчёты».
