# Документация проекта «Мой ассистент»

Добро пожаловать в документацию проекта.

Эта папка содержит все документы, описывающие продукт, архитектуру и процесс разработки.

## Документы

- DevelopmentGuide.md — инструкция совместной разработки.
- Vision.md — видение продукта.
- Architecture.md — описание архитектуры.
- Roadmap.md — план развития.
- ProjectState.md — текущее состояние проекта.
- Decisions.md — журнал архитектурных решений.
- Glossary.md — словарь терминов.

## Правило

Документация должна отражать текущее состояние проекта и обновляться одновременно с изменениями архитектуры.
