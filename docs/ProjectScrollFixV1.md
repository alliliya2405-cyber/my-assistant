# Project Scroll Fix v1

## Проблема

После визуального обновления карточек проектов у раскрытого проекта оставалась внутренняя вертикальная прокрутка. В результате пользователь прокручивал содержимое внутри карточки отдельно от страницы.

## Решение

Раскрытая карточка проекта использует обычную прокрутку страницы. Внутренний `max-height` и вертикальный `overflow` у `.project-details` отключены визуальным override.

## Что не меняется

- `app.js`;
- состояние раскрытия проектов;
- фокус проекта;
- редактирование и удаление;
- drag-and-drop;
- данные, Data Store и модели.

## Проверка

На опубликованной версии раскрытый проект должен расти по высоте вместе с содержимым и не показывать отдельную вертикальную полосу прокрутки внутри карточки.
