# Педагогический дизайн курсов — с чего начинать новый чат

Это контрольная точка проекта **«Педагогический дизайн курсов»**.

## Правило для ChatGPT в начале нового чата

Прежде чем продолжать работу по проекту:

1. Прочитать этот файл.
2. Прочитать `01_PROJECT_STATE.md` целиком.
3. При необходимости свериться с `02_DECISIONS.md`, если новый запрос затрагивает уже принятые решения.
4. Сначала восстановить и кратко проверить про себя:
   - что это за проект;
   - как он сейчас устроен;
   - что уже сделано и проверено;
   - какие решения зафиксированы;
   - над чем идет работа сейчас;
   - какое **одно действие является следующим**;
   - что сейчас не нужно менять;
   - что отложено.
5. Только после этого выполнять новый запрос пользователя.

## Правило обновления

После каждого значимого результата проекта ChatGPT должен самостоятельно обновлять `01_PROJECT_STATE.md`.

`02_DECISIONS.md` обновляется только тогда, когда принято новое устойчивое решение, которое не следует заново обсуждать в каждом чате.

Значимый результат — это, например:
- утвержденная или существенно уточненная модель;
- новый рабочий документ, который становится опорным;
- проверенный демонстрационный образец;
- изменение текущего фокуса;
- завершение следующего шага;
- новое решение о границах проекта, КЭС/КЭМ, архитектуре курса или способе работы методистов.

## Важный принцип

Этот контроль не заменяет содержательные документы. Он хранит **точку продолжения проекта**. Если для работы требуется конкретная таблица, тетрадь, программа или методические рекомендации, нужно использовать соответствующий исходный материал, а не восстанавливать его по памяти.

## Где лежит текущее состояние

- `01_PROJECT_STATE.md` — актуальная точка проекта человеческим языком.
- `02_DECISIONS.md` — журнал устойчивых решений и ограничений.

Последнее правило: **не создавать параллельную систему контроля в другом месте, пока эта схема работает.**
